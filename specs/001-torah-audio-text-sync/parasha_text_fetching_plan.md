# Plan: Fetch All Hebrew Text for Parasha Aliyot from Sefaria API

## Context

You want to decouple the text retrieval process from the video generation pipeline. Currently, the system fetches Hebrew text verse-by-verse during video processing, which is inefficient (7 API calls for one Aliyah). This plan creates a standalone text fetching capability that can retrieve all Hebrew text for all 7 Aliyot of a Parasha in one efficient operation.

**Problem**:
- Text fetching is tightly coupled to video processing pipeline
- Per-verse fetching is slow (53 API calls for full Parasha האזינו)
- Aliyah verse ranges are hardcoded
- No way to pre-fetch or batch-fetch text independently

**Goal**:
Create a decoupled text fetching module that can retrieve all Aliyot text for any Parasha efficiently, using batch API calls and proper caching.

## Current State Analysis

**What Exists:**
- ✅ `SefariaClient.get_verse()` - Fetches single verse (API v3)
- ✅ `SefariaClient.get_range()` - Fetches verse range (API v2) **but unused**
- ✅ `CachedSefariaClient` - File-based per-verse caching
- ✅ Aliyah verse ranges for האזינו hardcoded in `pipeline.py` (lines 106-120)

**Current Inefficiency:**
```python
# Current approach in pipeline.py (lines 129-132)
for verse_num in range(verse_range[0], verse_range[1]):
    hebrew_text = self.text_client.get_verse("Deuteronomy", 32, verse_num)
    verses.append((f"Deuteronomy 32:{verse_num}", hebrew_text))

# For Haazinu Rishon (verses 1-6): 6 API calls
# For entire Haazinu (verses 1-52): 52 API calls
```

**What's Missing:**
- ❌ Batch fetching capability using `get_range()`
- ❌ Centralized Aliyah configuration (not hardcoded)
- ❌ Standalone text fetching module (decoupled from pipeline)
- ❌ Ability to pre-fetch all Aliyot at once

## Proposed Solution

Create a new **`ParashaTextFetcher`** service that:

1. **Centralizes Aliyah verse ranges** in a configuration file
2. **Batch-fetches entire Aliyah ranges** using `get_range()` (1 API call per Aliyah)
3. **Pre-fetches all 7 Aliyot** for a Parasha in one operation
4. **Leverages existing cache** to avoid redundant API calls
5. **Is decoupled** from the video processing pipeline

### Design Overview

```
┌─────────────────────────────────────────┐

├─────────────────────────────────────────┤

              │

```

### API Efficiency Comparison

**Current (per-verse):**
```
Aliyah Rishon (6 verses): 6 API calls
Full Parasha (52 verses): 52 API calls
```

**Proposed (batch per-aliyah):**
```
Aliyah Rishon: 1 API call → get_range(32, 1, 32, 6)
Full Parasha: 7 API calls (one per aliyah)
```

**Savings:** 86% reduction in API calls (52 → 7)

### 2. Create ParashaTextFetcher Service

**File:** `src/services/text/parasha_fetcher.py` (NEW)

Standalone service for fetching all Aliyah text:

```python
# Generated by Claude Code
"""Service for fetching Torah text for entire Parashot and Aliyot."""

from pathlib import Path
from typing import NamedTuple

import tomli
from src.services.text.sefaria_client import CachedSefariaClient
from src.lib.logging import get_logger

logger = get_logger(__name__)


class AliyahRange(NamedTuple):
    """Verse range for an Aliyah."""
    name: str  # Hebrew name (ראשון, שני, etc.)
    start_verse: int
    end_verse: int  # Exclusive


class ParashaMetadata(NamedTuple):
    """Metadata about a Parasha."""
    parasha_name: str  # Hebrew name
    book: str  # English book name
    chapter: int
    total_verses: int
    aliyot: list[AliyahRange]


class ParashaTextFetcher:
    """Fetch Hebrew text for Torah Parashot and Aliyot.

    Provides efficient batch fetching of verse ranges for entire
    Parashot or individual Aliyot, leveraging the Sefaria API
    and file-based caching.

    Example:
        >>> fetcher = ParashaTextFetcher()
        >>>
        >>> # Fetch single Aliyah
        >>> verses = fetcher.fetch_aliyah_text("האזינו", "ראשון")
        >>> # Returns: [("Deuteronomy 32:1", "hebrew..."), ...]
        >>>
        >>> # Fetch entire Parasha (all 7 Aliyot)
        >>> all_aliyot = fetcher.fetch_all_aliyot_text("האזינו")
        >>> # Returns: {"ראשון": [...], "שני": [...], ...}
    """

    def __init__(
        self,
        config_path: Path | None = None,
        text_client: CachedSefariaClient | None = None,
    ):
        """Initialize fetcher with configuration.

        Args:
            config_path: Path to aliyah_ranges.toml (default: data/aliyah_ranges.toml)
            text_client: Sefaria client (default: creates new CachedSefariaClient)
        """
        self.config_path = config_path or Path("data/aliyah_ranges.toml")
        self.text_client = text_client or CachedSefariaClient()

        # Load configuration on init
        self._config = self._load_config()
        logger.info(f"ParashaTextFetcher initialized", config_path=str(self.config_path))

    def _load_config(self) -> dict:
        """Load aliyah ranges from TOML configuration."""
        if not self.config_path.exists():
            raise FileNotFoundError(
                f"Aliyah configuration not found: {self.config_path}"
            )

        with open(self.config_path, "rb") as f:
            return tomli.load(f)

    def get_parasha_metadata(self, parasha_name: str) -> ParashaMetadata:
        """Get metadata for a Parasha.

        Args:
            parasha_name: Hebrew name (e.g., "האזינו")

        Returns:
            ParashaMetadata with book, chapter, and aliyot ranges

        Raises:
            ValueError: If parasha not found in configuration
        """
        # Search config for matching parasha
        for key, section in self._config.items():
            if "." in key and section.get("parasha_name") == parasha_name:
                # Parse aliyot from subsections
                aliyot = []
                parasha_key = key

                # Find all aliyah subsections
                for aliyah_key in self._config.keys():
                    if aliyah_key.startswith(parasha_key + "."):
                        aliyah_config = self._config[aliyah_key]
                        aliyot.append(AliyahRange(
                            name=aliyah_config["name"],
                            start_verse=aliyah_config["start_verse"],
                            end_verse=aliyah_config["end_verse"],
                        ))

                # Sort by start_verse to ensure correct order
                aliyot.sort(key=lambda a: a.start_verse)

                return ParashaMetadata(
                    parasha_name=section["parasha_name"],
                    book=section["book"],
                    chapter=section["chapter"],
                    total_verses=section["total_verses"],
                    aliyot=aliyot,
                )

        raise ValueError(f"Parasha not found in configuration: {parasha_name}")

    def fetch_aliyah_text(
        self,
        parasha_name: str,
        aliyah_name: str,
    ) -> list[tuple[str, str]]:
        """Fetch Hebrew text for a single Aliyah.

        Uses batch API call to fetch entire verse range at once
        (more efficient than per-verse fetching).

        Args:
            parasha_name: Hebrew parasha name (e.g., "האזינו")
            aliyah_name: Hebrew aliyah name (e.g., "ראשון")

        Returns:
            List of (reference, hebrew_text) tuples
            Example: [("Deuteronomy 32:1", "הַאֲזִינוּ..."), ...]

        Raises:
            ValueError: If parasha or aliyah not found
        """
        metadata = self.get_parasha_metadata(parasha_name)

        # Find matching aliyah
        aliyah_range = None
        for aliyah in metadata.aliyot:
            if aliyah.name == aliyah_name:
                aliyah_range = aliyah
                break

        if not aliyah_range:
            raise ValueError(
                f"Aliyah '{aliyah_name}' not found in {parasha_name}"
            )

        logger.info(
            f"Fetching aliyah text",
            parasha=parasha_name,
            aliyah=aliyah_name,
            verse_range=f"{aliyah_range.start_verse}-{aliyah_range.end_verse}",
        )

        # Batch fetch entire aliyah range in ONE API call
        verses = self.text_client.get_range(
            book=metadata.book,
            chapter_start=metadata.chapter,
            verse_start=aliyah_range.start_verse,
            chapter_end=metadata.chapter,
            verse_end=aliyah_range.end_verse,
        )

        logger.info(
            f"Fetched aliyah text",
            parasha=parasha_name,
            aliyah=aliyah_name,
            verse_count=len(verses),
        )

        return verses

    def fetch_all_aliyot_text(
        self,
        parasha_name: str,
    ) -> dict[str, list[tuple[str, str]]]:
        """Fetch Hebrew text for all Aliyot in a Parasha.

        Efficiently fetches all 7 Aliyot using 7 batch API calls
        (one per aliyah) instead of 52+ individual verse calls.

        Args:
            parasha_name: Hebrew parasha name (e.g., "האזינו")

        Returns:
            Dictionary mapping aliyah name to verses
            Example:
            {
                "ראשון": [("Deut 32:1", "text"), ...],
                "שני": [("Deut 32:7", "text"), ...],
                ...
            }
        """
        metadata = self.get_parasha_metadata(parasha_name)

        logger.info(
            f"Fetching all aliyot for parasha",
            parasha=parasha_name,
            aliyah_count=len(metadata.aliyot),
        )

        result = {}

        for aliyah in metadata.aliyot:
            verses = self.fetch_aliyah_text(parasha_name, aliyah.name)
            result[aliyah.name] = verses

        total_verses = sum(len(verses) for verses in result.values())
        logger.info(
            f"Fetched all aliyot",
            parasha=parasha_name,
            aliyah_count=len(result),
            total_verses=total_verses,
        )

        return result
```

# Generated by Claude Code
from dataclasses import dataclass, field
from pathlib import Path

@dataclass
class BatchResult:
    """Track batch processing results."""

    total: int = 0
    successful: list[Path] = field(default_factory=list)
    failed: list[tuple[Path, str]] = field(default_factory=list)
    skipped: list[tuple[Path, str]] = field(default_factory=list)

    @property
    def success_rate(self) -> float:
        if self.total == 0:
            return 0.0
        return len(self.successful) / self.total

    @property
    def has_failures(self) -> bool:
        return len(self.failed) > 0
```

valid_files = []
for audio_file in audio_files:
    try:
        parse_audio_filename(audio_file.name)  # Validates format
        valid_files.append(audio_file)
    except ValueError as e:
        logger.warning(f"Skipping invalid filename: {audio_file.name}")

if not valid_files:
    click.echo("✗ No valid audio files found", err=True)
    sys.exit(1)

click.echo(f"Found {len(valid_files)} valid audio files")

# Process each file
from src.services.pipeline import ProcessingPipeline
from src.models.batch_result import BatchResult

pipeline = ProcessingPipeline()
result = BatchResult(total=len(valid_files))

for audio_file in valid_files:
    click.echo(f"\nProcessing: {audio_file.name}")

    try:
        video = pipeline.process_single_aliyah(audio_file, output_dir=output)
        result.successful.append(video.file_path)
        click.echo(f"  ✓ Success: {video.file_path.name}")

    except Exception as e:
        result.failed.append((audio_file, str(e)))
        logger.error(f"Processing failed: {audio_file.name}: {e}")
        click.echo(f"  ✗ Failed: {e}", err=True)

# Print summary
click.echo(f"\n{'='*60}")
click.echo("Batch Processing Summary")
click.echo(f"{'='*60}")
click.echo(f"Processed:    {result.total}")
click.echo(f"Successful:   {len(result.successful)}")
click.echo(f"Failed:       {len(result.failed)}")

if result.successful:
    click.echo("\nGenerated videos:")
    for path in result.successful:
        click.echo(f"  {path}")

# Exit codes
if len(result.failed) == result.total:
    sys.exit(1)  # All failed
elif result.has_failures:
    sys.exit(2)  # Partial success
else:
    sys.exit(0)  # All successful
```

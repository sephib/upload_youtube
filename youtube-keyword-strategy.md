# YouTube Keyword Strategy - Torah Reading Educational Platform

**Version:** 1.0
**Date:** March 24, 2026
**Character Budget:** 500 chars per video
**Tag Target:** 8-10 tags per video
**Character Usage Goal:** 75% (375 chars)

## TIER 1: Universal Keywords (ALL Videos)

**Purpose:** Brand identity, general discoverability, language markers
**Count:** 4 tags (mandatory on every video)
**Character Budget:** ~50 chars (Torah portions) / ~34 chars (Megillot)

### For Torah Portions (Parashot)

```
קריאה בתורה    (14 chars) - "Torah reading" - Primary Hebrew discovery
טעמי המקרא     (11 chars) - "Ta'amei Hamikra" - Cantillation tradition
טעמים          (5 chars)  - "Cantillation marks" - Technical identifier
Torah Reading  (13 chars) - Primary English discovery
```

**Total:** 43 chars + separators = ~50 chars

### For Megillot (Scrolls)

```
מגילה          (5 chars)  - "Megillah/Scroll" - Primary Hebrew discovery
תורה           (4 chars)  - "Torah" - Broad reach
טעמים          (5 chars)  - "Cantillation marks" - Technical identifier
Torah Reading  (13 chars) - Primary English discovery
```

**Total:** 27 chars + separators = ~34 chars

**Rationale:**
- `קריאה בתורה` / `מגילה` distinguish between weekly portions and scrolls
- `טעמי המקרא` establishes religious/educational context
- `טעמים` targets users learning cantillation
- `Torah Reading` captures English-speaking learners
- All are high-volume search terms

## TIER 2: Playlist-Level Keywords (Parasha/Megillah Specific)

**Purpose:** Group videos by reading context, enable playlist discovery
**Count:** 4-5 tags per video
**Character Budget:** ~150 chars (flexible based on parasha name length)

### Structure: Torah Portions (Parashot)

**Pattern:** Hebrew book + Hebrew parasha + English book + English transliteration

Naso           (4 chars)  - Parasha transliteration

**Total:** 28 chars + separators = ~36 chars

#### Example: Parashat Ki Tisa (Exodus)

```

```

**Total:** 29 chars + separators = ~37 chars

### Structure: Megillot (Scrolls)

**Pattern:** Hebrew name + English name + Transliteration + Seasonal tag (if budget allows)

Sukkot         (6 chars)  - Seasonal tag (optional)

**Total with seasonal:** 30 chars + separators = ~37 chars
**Total without seasonal:** 24 chars + separators = ~30 chars

#### Example: Megillat Esther

```

Esther         (6 chars)  - English name
Purim          (5 chars)  - Seasonal tag (optional)
```

**Total with seasonal:** 15 chars + separators = ~21 chars
**Total without seasonal:** 10 chars + separators = ~15 chars

## TIER 3: Video-Specific Keywords (Aliyah/Chapter)

**Purpose:** Precise targeting for students preparing specific sections
**Count:** 2 tags per video (Hebrew + English)
**Character Budget:** ~25 chars

### Structure: Torah Aliyot

**Pattern:** Hebrew name + English transliteration

```

שני + Sheni          (3 + 5 = 8 chars)   - Second aliyah
שלישי + Shlishi      (5 + 7 = 12 chars)  - Third aliyah
רביעי + Reviei       (5 + 6 = 11 chars)  - Fourth aliyah
חמישי + Chamishi     (5 + 8 = 13 chars)  - Fifth aliyah
שישי + Shishi        (4 + 6 = 10 chars)  - Sixth aliyah
שביעי + Shevii       (5 + 6 = 11 chars)  - Seventh aliyah
מפטיר + Maftir       (5 + 6 = 11 chars)  - Maftir
הפטרה + Haftara      (6 + 7 = 13 chars)  - Haftara
```

**Average:** 11 chars + separators = ~14 chars per video

## IMPLEMENTATION GUIDELINES

### 1. Consistency Rules

**Same across entire playlist:**
- All Tier 1 tags (universal)
- All Tier 2 tags (playlist-specific)
- All Tier 4 tags (audience)

**Varies per video:**
- Only Tier 3 tags change (aliyah/chapter identifier)

### 2. Character Budget Management

**Minimum viable (50% budget = 250 chars):**
- Use standard Tier 1-4 as shown in Examples 1-2
- Results in 17-18 tags, ~180-200 chars

**Recommended (75% budget = 375 chars):**
- Add extended Tier 2 (Hebrew alternatives)
- Add extended Tier 3 (fuller forms)
- Add extended Tier 4 (intent + seasonal tags)
- Results in 25-30 tags, ~350-380 chars

**Maximum (100% budget = 500 chars):**
- Add all available alternatives
- Include niche/long-tail keywords
- Results in 35-40 tags, ~480-500 chars

### 3. Tag Priority Order

When budget is limited, remove tags in this order (lowest priority first):

1. Extended Tier 4 (niche intent tags)
2. Seasonal tags (Tier 2 for Megillot)
3. Extended Tier 3 (fuller aliyah forms)
4. Hebrew alternatives (Tier 2)
5. Tier 4 secondary audience tags

**Never remove:**
- All Tier 1 tags (universal)
- Core Tier 2 tags (parasha/megillah name + book)
- Core Tier 3 tags (aliyah/chapter identifier)
- Primary Tier 4 tags (Bar/Bat Mitzvah + Ashkenaz)

### 4. Quality Over Quantity

**Prefer:**
- Accurate, commonly-searched terms
- Both Hebrew and English where appropriate
- Consistent tagging across playlist

**Avoid:**
- Duplicate meanings (e.g., don't include both "Torah" and "Chumash" if budget-constrained)
- Over-specific long-tail (e.g., "Bar Mitzvah Parashat Naso Third Aliyah Ashkenaz")
- Keyword stuffing with low-value tags

## AUTOMATION NOTES

For implementation in `torah-sync` system:

```python
# Tier 1: Based on playlist type
if playlist.type == PlaylistType.PARASHA:
    tier1 = ["קריאה בתורה", "תורה", "טעמים", "Torah Reading"]
elif playlist.type == PlaylistType.MEGILLAH:
    tier1 = ["מגילה", "תורה", "טעמים", "Torah Reading"]

# Tier 2: Based on playlist metadata
tier2 = [
    playlist.hebrew_name,        # e.g., "נשא"
    playlist.book_hebrew,         # e.g., "במדבר"
    playlist.english_name,        # e.g., "Naso"
    playlist.book_english,        # e.g., "Numbers"
    playlist.book_transliteration # e.g., "Bamidbar"
]

# Tier 3: Based on aliyah/chapter
if playlist.type == PlaylistType.PARASHA:
    tier3 = [alya.hebrew_name, alya.english_name]  # e.g., ["ראשון", "Rishon"]
elif playlist.type == PlaylistType.MEGILLAH:
    tier3 = [f"פרק {alya.order_num}", f"Chapter {alya.order_num}"]

# Tier 4: Standard audience tags
tier4 = [
    "בר מצווה", "Bar Mitzvah",
    "בת מצווה", "Bat Mitzvah",
    "אשכנז", "Ashkenaz",
    "לימוד תורה"
]

# Combine and format
tags = tier1 + tier2 + tier3 + tier4
youtube_tags = ", ".join(tags)
```
